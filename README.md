# 沙坡尾街区展示网站

这是一个使用Next.js、React、TypeScript、Tailwind CSS和Framer Motion构建的沙坡尾街区展示网站。网站采用黑白风格，展示了沙坡尾的历史文化、发展时间轴、特色店铺、潮流文化和IP形象。

## 技术栈

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Spline (3D交互)

## 功能组件

- Navbar - 导航栏
- Header - 标题界面
- Overview - 沙坡尾概述
- Timeline - 发展时间轴
- Shops - 特色店铺
- Culture - 潮流文化
- Mascot - IP形象
- Footer - 页脚

## 本地开发

1. 安装依赖

```bash
npm install
```

2. 启动开发服务器

```bash
npm run dev
```

3. 打开浏览器访问 http://localhost:3000

## 构建生产版本

```bash
npm run build
```

## 部署

### 部署到Vercel (推荐)

1. 将项目推送到GitHub仓库
2. 在Vercel中导入该仓库
3. 部署完成后，Vercel将提供一个可访问的URL

详细部署指南请参考[DEPLOYMENT.md](../DEPLOYMENT.md)文件。
